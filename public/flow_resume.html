Save, load and resume for ImageNet1-Latent-Flow-Matching-XM

After these edits the notebook encodes the latents one time and loads them from disk on every later start. It saves the flow model, the optimizer and the loss history at the end of every epoch, and every 30 minutes inside an epoch.

The blocks follow the notebook from top to bottom. A definition cell only defines functions: it is safe to run again at any time. An action cell is short and does one thing. Every cell that overwrites the model or a file is at the bottom of the notebook, below a STOP line.

  2. Set RUN_NAME to a name for this training run.

  2. Paste block 2 into the new cell.

Helpers

  1. Add a new cell directly below the cell that starts with #log metrics.
  2. Paste block 3 into the new cell. You can collapse this cell.

Cache cells (below the init-models cell)

  2. Replace the line for epoch in range(num_epochs): with block 5A.
  3. Paste block 5B on a new line above report_steps += 1. Keep the eight spaces.

Bottom of the notebook

  1. Go to the cell that starts with # load flow model.
  2. Add four new cells directly above it.
  3. Paste blocks 6A, 6B, 6C and 6D into them, in that order.

First run

  1. Restart the kernel.
  2. Run the cells in order, down to and including the cell that starts with # MAIN TRAINING LOOP.
    Result, this first time only: each cache cell encodes as before and ends with z cache [train]: saved 1,281,167 to …. Each epoch ends with saved <RUN_NAME> | epochs done N.
Do not use "Run All". It also runs the cells below the STOP line.

Resume after a kernel restart

  1. Run the cells in order, from the top down to and including the cell that starts with #compile and speed.
    Result: each cache cell prints z cache [train]: loaded 1,281,167 latents from … in seconds. If it prints rejected, encoding, the lines below it name what changed.
  2. Scroll to the bottom of the notebook, below the STOP line.
  3. Run the cell that starts with # RESUME A RUN.
    Result: resumed <RUN_NAME> … epochs done: N | steps logged: … | lr: … | optimizer restored.
  4. Scroll back up to the cell that starts with # MAIN TRAINING LOOP and run it.
    Result: the first step line shows a step count above N × batches per epoch, and the next epoch line is EPOCH N+1.

A new run needs no step at the bottom. With no resume, the loop starts at epoch 0.

Only the latents, in a new notebook

  1. Run the set-up above one time, so the two cache files exist.
  2. In the new notebook, paste block E1 into a cell and run it.
    Result: no output. The cell only defines load_z_cache and latent_loader. You can collapse it and leave it.
  3. Paste block E2 into the next cell.
  4. If the new notebook uses another autoencoder, change AE_NAME in block E2.
  5. Run the E2 cell.
    Result: z cache [train]: (1281167, 48, 48) torch.bfloat16 from … and the same line for val.

E1 defines, E2 acts. The two cells need no encoder, no ImageNet loader and no flow model. They only read $ML_CHECKPOINTS. They do not check that the file matches an encoder, because they do not load one.

Notes

  • Latents: $ML_CHECKPOINTS/z_cache/<ae_name>_128px/train.pt (about 5.5 GiB) and val.pt. A cache is used only when ae_name, the image size, the image count, the token dimensions and the file encoder.pt2 (size and modified time) are the same as when it was written.
  • Runs: $ML_CHECKPOINTS/flow/<RUN_NAME>/latest.pt, plus epoch_010.pt, epoch_020.pt, … as kept copies.
  • The resume cell takes arguments: load_run("other_run") loads another run, and load_run(tag="epoch_010") loads a kept copy.
  • load_run() restores the learning rate that was saved. The #drop lr cell changes it again if you run that cell after the resume cell.
  • A save inside an epoch records the epoch as not done. A resume from it repeats that epoch from its first batch, with the newer weights. The loss history keeps the steps already logged.
  • If you interrupt the loop and run the loop cell again without a restart, it continues at the first epoch that is not done.
  • The helpers cell (block 3) keeps no state. The epoch count and the autosave clock live on flow_model, so running the helpers cell again changes nothing. A new init_models() starts both from zero.
  • The validation cache cell no longer builds test_dataloader. Block 2 builds it in the data cells, so the later probe cells that read it still work.
  • The loss history is stored as float32.
  • The three old cells at the bottom (name = …, # load flow model, # save flow model) can stay. The new helpers do not use them. Their flow_model key is the same, so the old load cell can also read latest.pt.
  • A model with new parameters still loads: the new parameters keep their initial values, and the printout names them. The optimizer state is then not restored.
  • The STOP line in block 6A is shorter than the one in the AE notebook, to fit 72 characters.

# ---------- save / resume / z cache helpers: definitions only ---- #
# Running this cell loads nothing, saves nothing and changes nothing.
import shutil

from torch.utils.data import TensorDataset, DataLoader


def _atomic_save(obj, path):
    # Write a temp file, then swap it in. A crash in the middle
    # leaves the previous file as it was.
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(path.name + ".tmp")
    torch.save(obj, tmp)
    os.replace(tmp, path)


def _z_cache_meta(n_images):
    # What a cache file must match to be used again.
    encoder_file = (
        Path(os.environ["ML_MODELS"]) / ae_name / "encoder.pt2"
    )
    stat = encoder_file.stat()

    return {
        "ae_name": ae_name,
        "image_size": int(IMAGE_SIZE),
        "n_images": int(n_images),
        "n_latent_tokens": int(n_latent_tokens),
        "emb_dim": int(emb_dim),
        # size and modified time of encoder.pt2
        "encoder_file": [int(stat.st_size), int(stat.st_mtime)],
    }


def z_cache(split, loader, n_images, force=False):
    # Latents of one split. Loads the file when it matches this
    # encoder and image size. Otherwise encodes and saves.
    path = (
        Path(os.environ["ML_CHECKPOINTS"])
        / "z_cache"
        / f"{ae_name}_{IMAGE_SIZE}px"
        / f"{split}.pt"
    )
    meta = _z_cache_meta(n_images)

    if force:
        print(f"z cache [{split}]: force=True, encoding again")

    elif not path.exists():
        print(f"z cache [{split}]: no file at {path}, encoding")

    else:
        saved = torch.load(
            path,
            map_location="cpu",
            weights_only=True,
        )
        changed = [
            key for key in meta
            if saved["meta"].get(key) != meta[key]
        ]

        if not changed:
            z, y = saved["z"], saved["y"]
            print(
                f"z cache [{split}]: loaded {len(z):,} latents "
                f"from {path} "
                f"({z.numel() * z.element_size() / 1024**3:.2f}"
                f" GiB)"
            )
            return z, y

        print(f"z cache [{split}]: {path} rejected, encoding")
        for key in changed:
            print(
                f"  {key}: file has {saved['meta'].get(key)!r}"
                f", notebook has {meta[key]!r}"
            )
        del saved

    z_all = torch.empty(
        n_images,
        n_latent_tokens,
        emb_dim,
        dtype=torch.bfloat16,
    )
    y_all = torch.empty(
        n_images,
        dtype=torch.long,
    )

    write_idx = 0

    with torch.inference_mode():

        for i, (images, labels) in enumerate(loader):

            images = images.to(
                device,
                non_blocking=True,
            )

            z = encoder(images)

            end_idx = min(
                write_idx + z.shape[0],
                n_images,
            )
            n = end_idx - write_idx

            z_all[write_idx:end_idx].copy_(
                z[:n].to(
                    device="cpu",
                    dtype=torch.bfloat16,
                )
            )
            y_all[write_idx:end_idx].copy_(
                labels[:n].to(
                    device="cpu",
                    dtype=torch.long,
                )
            )

            write_idx = end_idx

            if i % 100 == 0:
                print(
                    f"{split} batch {i:,} | "
                    f"{write_idx:,}/{n_images:,} "
                    f"({100 * write_idx / n_images:.1f}%)"
                )

    # Safety in case the loader produced fewer images than expected
    if write_idx < n_images:
        z_all = z_all[:write_idx].clone()
        y_all = y_all[:write_idx].clone()

    _atomic_save({"z": z_all, "y": y_all, "meta": meta}, path)
    print(f"z cache [{split}]: saved {len(z_all):,} to {path}")

    return z_all, y_all


def load_z_cache(ae_name, split="train", image_size=128):
    # Needs no encoder, no image loader and no flow model.
    path = (
        Path(os.environ["ML_CHECKPOINTS"])
        / "z_cache"
        / f"{ae_name}_{image_size}px"
        / f"{split}.pt"
    )
    saved = torch.load(
        path,
        map_location="cpu",
        weights_only=True,
    )
    z, y = saved["z"], saved["y"]
    print(
        f"z cache [{split}]: {tuple(z.shape)} {z.dtype} "
        f"from {path}"
    )
    return z, y


def latent_loader(z, y, train, batch_size=64):
    # train=True: shuffled, full batches only.
    # train=False: fixed order, every sample.
    return DataLoader(
        TensorDataset(z, y),
        batch_size=batch_size,
        shuffle=train,
        num_workers=0,
        pin_memory=True,
        drop_last=train,
    )


def _run_dir(run_name=None):
    return (
        Path(os.environ["ML_CHECKPOINTS"])
        / "flow"
        / (run_name or RUN_NAME)
    )


def save_run(epochs_done, tag="latest", keep=True):
    # Everything needed to continue: model, optimizer, logs.
    state = {
        name.replace("_orig_mod.", ""): value
        for name, value in flow_model.state_dict().items()
    }

    checkpoint = {
        "flow_model": state,
        "optimizer": optimizer.state_dict(),
        "logs": {
            name: torch.tensor(values, dtype=torch.float32)
            for name, values in logs.items()
        },
        "epochs_done": int(epochs_done),
        "config": {
            "ae_name": ae_name,
            "image_size": int(IMAGE_SIZE),
            "n_latent_tokens": n_latent_tokens,
            "emb_dim": emb_dim,
            "num_blocks": num_blocks,
            "n_heads": n_heads,
            "head_size": head_size,
            "flow_emb_dim": flow_emb_dim,
            "flow_noise_scale": flow_noise_scale,
            "XM_K": XM_K,
            "XM_N": XM_N,
        },
    }

    path = _run_dir() / f"{tag}.pt"
    _atomic_save(checkpoint, path)

    # The run state lives on the model, not in this cell, so
    # running this cell again never resets it.
    flow_model.epochs_done = int(epochs_done)
    flow_model.last_save_time = time.perf_counter()

    note = ""
    if (
        keep
        and epochs_done > 0
        and epochs_done % KEEP_EVERY_EPOCHS == 0
    ):
        kept = path.with_name(f"epoch_{epochs_done:03d}.pt")
        # copy to a temp name, then swap it in: stopping the
        # kernel in the middle never leaves a half-written copy
        tmp = kept.with_name(kept.name + ".tmp")
        shutil.copy2(path, tmp)
        os.replace(tmp, kept)
        note = f" (+ {kept.name})"

    print(f"saved {RUN_NAME} | epochs done {epochs_done}{note}")


def load_run(run_name=None, tag="latest"):
    # Restore model, optimizer and logs in place. The training
    # loop then starts at the saved epoch.
    global start_epoch

    path = _run_dir(run_name) / f"{tag}.pt"
    checkpoint = torch.load(
        path,
        map_location=device,
        weights_only=True,
    )

    saved_ae = checkpoint["config"]["ae_name"]
    if saved_ae != ae_name:
        print(
            f"WARNING: run was trained on {saved_ae!r}, "
            f"notebook uses {ae_name!r}"
        )

    model = getattr(flow_model, "_orig_mod", flow_model)
    result = model.load_state_dict(
        checkpoint["flow_model"],
        strict=False,
    )
    if result.missing_keys:
        print("not in checkpoint (kept as initialized):")
        print("  " + ", ".join(result.missing_keys))
    if result.unexpected_keys:
        print("in checkpoint but not in model (ignored):")
        print("  " + ", ".join(result.unexpected_keys))

    try:
        optimizer.load_state_dict(checkpoint["optimizer"])
        optimizer_note = "optimizer restored"
    except (ValueError, KeyError, RuntimeError) as error:
        optimizer_note = f"optimizer NOT restored ({error})"

    logs.clear()
    for name, values in checkpoint["logs"].items():
        logs[name] = values.tolist()

    start_epoch = checkpoint["epochs_done"]
    flow_model.epochs_done = start_epoch

    print(
        f"resumed {run_name or RUN_NAME} from {path}\n"
        f"  epochs done: {start_epoch} | "
        f"steps logged: {len(logs.get('flow_loss', [])):,} | "
        f"lr: {optimizer.param_groups[0]['lr']:.2e} | "
        f"{optimizer_note}"
    )

    return start_epoch


def resume_epoch():
    # Epoch the training loop starts at. 0 for a new model.
    return getattr(flow_model, "epochs_done", 0)


def autosave(epoch):
    # Called every step. Saves when AUTOSAVE_MINUTES have passed
    # since the last save. A resume from this save repeats the
    # interrupted epoch.
    now = time.perf_counter()
    last = getattr(flow_model, "last_save_time", None)

    if last is None:
        # first step of a new model: start the clock
        flow_model.last_save_time = now

    elif now - last >= AUTOSAVE_MINUTES * 60:
        save_run(epoch, keep=False)
