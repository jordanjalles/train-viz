How to read it

  • Update size: how much a branch adds to the token stream, as a multiple of the stream it enters. 1 = the update is as large as the stream.
  • Loss rise when skipped: the block is replaced by "do nothing" and the test loss is measured again. This is what the block contributes. A skipped early block also hands the later blocks an input they never saw, so early blocks read high on this test.
  • Learned gain: each branch ends in a post-norm (weight 1e-4 at init) times a time gate (1 at init). Their product is the size the model gave the branch. The gates grew to between 10 and 100, so the product is far from small although the post-norm weights still are.
