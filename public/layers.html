What re-learns after a scale-up

Each column is one scale-up: a model trained at a low resolution continues at twice the resolution with the same weights. The number in a cell answers one question: how much more did this part of the network change in the 5,000 steps after the scale-up than it would have changed in 5,000 more steps at the old resolution? A value of 1 means "no more than usual". A value of 2 means "twice as much".

    How this was measured

    For a scale-up from a parent run at step S, the weights at S are compared with the weights 5,000 steps later. Change is the size of the difference divided by the size of the weights at S, pooled over all tensors of a part. The scale-up branch trains at the new resolution. The control is the parent run itself, 5,000 steps later at the old resolution. Both start from the same weights and optimizer state. Patch size is 16 at every resolution, so 32 px has 4 patches, 64 px has 16 and 128 px has 64.

    Limits: one run per condition, so small differences between columns are not reliable. A large change in weights does not prove that a part needed to change; a freezing test would show that.
