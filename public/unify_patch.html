Grey samples: the patch skip drops color

Notebook: ImageNet-Unify.ipynb. The loss is fine. The fixed skip path in the patch embed and un-embed carries brightness only, and the part that can carry color starts 10,000 times weaker.

Why

  • The numbers line up by accident. A 16 px patch has 768 values, ordered pixel by pixel as R, G, B. Your emb_dim is 256. ChannelGroupResize groups 768 / 256 = 3 consecutive values, which is exactly the R, G and B of one pixel.
  • Embed skip: it averages each group, so each token channel is the grey value of one pixel. A color image and its grey version give the same tokens.
  • Un-embed skip: it repeats each token channel over its group, so R = G = B in every output pixel.
  • Color can only come from the learned linear branches. They sit behind an RMSNorm with gain 1e-4. At init the color part of the un-embed output is about 0.00007, against 0.8 for the grey part. With lr = 1e-4 that gain grows slowly.
  • The AE notebook did not show this because its width was 336. 768 / 336 is not a whole number, so the groups did not line up with the three channels.

    # patch embed / un-embed with a colour-keeping skip (definitions only)


class PatchPoolSkip(nn.Module):
    """Fixed skip between the pixels of a patch and its token.

    Down: every colour channel of the p x p patch is average-pooled
    to k x k. The c * k * k values fill the first token channels;
    the rest are zero. Up: the reverse, with nearest upsampling.

    k is the largest size that divides the patch size and fits:
    c * k * k <= emb_dim. Because k divides p, every pixel is in
    exactly one block of the same size. The skip then treats all
    positions alike, and mirrors and quarter turns of a patch come
    out as mirrors and quarter turns.
    """
    def __init__(self, patch_size, c, emb_dim):
        super().__init__()
        self.p, self.c, self.emb_dim = patch_size, c, emb_dim
        fits = [
            k for k in range(1, patch_size + 1)
            if patch_size % k == 0 and c * k * k <= emb_dim
        ]
        assert fits, "emb_dim is smaller than the channels"
        self.k = max(fits)
        self.n_used = c * self.k * self.k

    def down(self, patches):
        # (B, T, c, p, p) -> (B, T, emb_dim)
        B, T = patches.shape[:2]
        x = F.adaptive_avg_pool2d(
            patches.reshape(B * T, self.c, self.p, self.p), self.k,
        ).reshape(B, T, self.n_used)
        return F.pad(x, (0, self.emb_dim - self.n_used))

    def up(self, tokens):
        # (B, T, emb_dim) -> (B, T, c, p, p)
        B, T = tokens.shape[:2]
        x = tokens[..., :self.n_used].reshape(
            B * T, self.c, self.k, self.k,
        )
        x = F.interpolate(x, size=(self.p, self.p), mode="nearest")
        return x.reshape(B, T, self.c, self.p, self.p)


class LinSkipPatchEmbed(nn.Module):
    def __init__(self, patch_size, c, emb_dim):
        super().__init__()
        self.p, self.c = patch_size, c
        n = c * patch_size * patch_size
        self.skip = PatchPoolSkip(patch_size, c, emb_dim)
        self.linear = nn.Linear(n, emb_dim, bias=False)
        self.norm = nn.RMSNorm(emb_dim)
        nn.init.constant_(self.norm.weight, 1e-4)

    def forward(self, x):
        B, C, H, W = x.shape
        assert H % self.p == 0 and W % self.p == 0
        p, rows, cols = self.p, H // self.p, W // self.p

        # (B, rows * cols, C, p, p): one small image per patch
        patches = (
            x.reshape(B, C, rows, p, cols, p)
            .permute(0, 2, 4, 1, 3, 5)
            .reshape(B, rows * cols, C, p, p)
        )
        flat = patches.reshape(B, rows * cols, C * p * p)

        return self.skip.down(patches) + self.norm(self.linear(flat))


class LinSkipUnEmbed(nn.Module):
    def __init__(self, patch_size, c, emb_dim):
        super().__init__()
        self.p, self.c = patch_size, c
        n = c * patch_size * patch_size
        self.skip = PatchPoolSkip(patch_size, c, emb_dim)
        self.linear = nn.Linear(emb_dim, n, bias=False)
        self.norm = nn.RMSNorm(n)
        nn.init.constant_(self.norm.weight, 1e-4)

    def forward(self, x, patch_rows, patch_cols):
        B, T = x.shape[:2]
        assert T == patch_rows * patch_cols
        p, c = self.p, self.c

        patches = (
            self.skip.up(x)
            + self.norm(self.linear(x)).reshape(B, T, c, p, p)
        )

        # (B, rows, cols, c, p, p) -> (B, c, rows * p, cols * p)
        return (
            patches.reshape(B, patch_rows, patch_cols, c, p, p)
            .permute(0, 3, 1, 4, 2, 5)
            .reshape(B, c, patch_rows * p, patch_cols * p)
        )

def check_patch_colour():
    embed = LinSkipPatchEmbed(patch_size, 3, emb_dim)
    un_embed = LinSkipUnEmbed(patch_size, 3, emb_dim)
    size = 2 * patch_size
    for name, rgb in (
        ("red", (1., 0., 0.)), ("green", (0., 1., 0.)),
        ("blue", (0., 0., 1.)),

            1, 3, size, size,

            .permute(0, 2, 4, 1, 3, 5)
            .reshape(1, 4, 3, patch_size, patch_size)
        ))
        mean = out.mean((0, 1, 3, 4))
        print(f"{name:<5} in -> out RGB",
              [round(v, 2) for v in mean.tolist()])

What the new skip does

Each color channel of a patch is average-pooled from 16 × 16 to 8 × 8, in 2 × 2 blocks. That gives 3 × 64 = 192 values, which fill the first 192 token channels. The last 64 are zero in the skip. The un-embed does the reverse: each value is repeated over its 2 × 2 block. So the default path through the model is a slightly blurred color image, not a sharp grey one. The learned linear branches are unchanged and add the detail.

  • The pooled size always divides the patch size. It is the largest such size that fits: 8 × 8 for emb_dim 192 to 767, and the full 16 × 16 for 768 or more. Every pixel is then in exactly one block of the same size, so the skip treats all positions alike. (My first version used 9 × 9 for width 256. Its blocks overlapped unevenly, so I changed it.)
  • Same class names and calls. LinSkipPatchEmbed and LinSkipUnEmbed keep their arguments, so the model cell does not change. ChannelGroupResize is gone.

Tested on the CPU against your notebook's cells. Old cells: an image and its grey version give identical tokens, and the un-embed skip output has R = G = B exactly. New cells: constant colors come back exact, a smooth color ramp comes back within 0.03, your model builds with them and trains. Not run on a GPU.
